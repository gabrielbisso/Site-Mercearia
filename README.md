<h2 id=JustificativadoProjeto>Justificativa do Projeto</h2>

> Este repositório reúne os arquivos e o código-fonte utilizados no desenvolvimento de um site de compra e venda para uma mercearia, criado como projeto final da disciplina de Desenvolvimento de Aplicações para Web (Cod. SL.DE.270) do curso Integral de <a href='https://intranet.ifsul.edu.br/catalogo/curso/174'>Informática para Interne</a>t do IFSul (2022).

<h2 id=ObjetivodoProjeto>Objetivo do Projeto</h2>

> Desenvolver uma aplicação completa que integre front-end, back-end e banco de dados (SQL) em um único ecossistema. O projeto tem como objetivo simular uma plataforma de vendas online, oferecendo experiência de compra aos usuários e ferramentas de gestão aos administradores, além de Disponibilizar um dashboard administrativo para análise de métricas, processamento de pedidos e gerenciamento de estoque, permitindo monitorar a operação do mercado em tempo real.

<h2 id=descricaodoprototipo>Descrição do Protótipo</h2>

> O protótipo é composto por uma série de telas que simulam o fluxo de um marketplace:

* #### Interface do Cliente
    Página inicial com carrosséis de produtos em destaque e filtros de busca.

    Catálogo exibindo categorias e ofertas, inspirado em componentes Bootstrap.

    Carrinho de compras para adicionar, remover ou atualizar itens.

    Checkout com opção de confirmar a compra e selecionar forma de pagamento.


* #### Interface do Administrador
    Tela de login para autenticação segura.

    Dashboard analítico com indicadores de vendas, estoque e pedidos em andamento.

    Gestão de pedidos: aprovação, envio, finalização ou cancelamento de compras diretamente pelo painel.

* #### Fluxo Geral
    O cliente acessa o site, navega pelo catálogo, adiciona produtos ao carrinho e conclui a compra.

    O administrador é notificado no dashboard, onde acompanha o status do pedido e realiza a gestão dos itens.

    Todas as interações são registradas no banco de dados, garantindo rastreabilidade das operações.
